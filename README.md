## <img src="https://img.shields.io/badge/01-ABOUT_ME-6F927D?style=flat-square&labelColor=0D1117" />

I'm a SaaS professional who spent years working around client enablement, functional support, and implementation.

Worked closely with users, clients, Dev and QA, sometimes BA, but <em>SRE was mostly a mystery to me.</em>

Then I started learning and writing code.

I wanted to understand more about the systems I've spent years supporting. And maybe also create something new to solve my own problems.

<strong>I cannot code from scratch.</strong> But I can copy and paste, and edit it.

Mostly just using LLM CLIs with the terminal and directories...

I use macOS right now. Had some Linux GUI experience, but never really went that deep. I used Windows in the past too.

Back when I was using Windows, I didn't understand when folks talked about cloning a repo.

I only used CMD, and somehow <em>cloning a repo was not part of the curriculum.</em>

Now I'm on a Mac, using the terminal, and apparently I finally understand what they were talking about.

<strong>Windows is a pain in the arse.</strong>

Linux and Mac are very easy.

Homebrew, CLI, terminal, copy, paste, Enter, done.

<em>Amazing.</em>

I didn't understand how to clone a GitHub repo.

Didn't understand what a pull request or merge was.

<strong>What is a commit?</strong>

Git version control?

...all very important words that somehow meant absolutely nothing to me at the time.

When I was in high school, I just used FileZilla for direct HTML and CSS FTP and XAMPP.

That was basically my idea of development.

I didn't understand Docker, Kubernetes, containers, etc. etc.

I had only ever used VirtualBox, which was already quite impressive in my little world.

People sometimes mistake me for an infrastructure support engineer, such as an SRE (I don't even know why)... but I don't.

Well... I guess I need to learn about it anyway.

So here I am, learning all the things I apparently should have known already...

And so this GitHub is a little messy.

<sub>Thank you.</sub>
